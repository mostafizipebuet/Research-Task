# Codebook development log

## Version 1.0 — 2026-10-21

- Developed 25 initial reason proposals from representative explanations across observed requirement–criterion groups.
- Inspected explanations unmatched by the initial rules and refined lexical patterns for explicit synonyms.
- Added three rare proposals: implied power constraint, assumed component existence, and claimed environment-value mismatch.
- Restricted context-dependent patterns to relevant requirements. Criterion IDs are not used to decide reason labels.
- Added checks to avoid treating missing measurement conditions as missing numerical provenance.
- Retained multi-label matches, exact matched spans, and a visible unresolved state.
- This was exploratory work using the full corpus. It is not a blinded, independent or held-out validation study. No accuracy estimate is claimed.
- All initial category statuses remain `proposed`.
